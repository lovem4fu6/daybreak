# 破曉

把人生當成升級遊戲的手機 App。每天打開、回報三個任務、累積經驗升級。

## 規則

| 任務 | 做法 | 獎勵 |
|---|---|---|
| 禁炸令 | 每天回報「守住了」或「破戒了」 | +30 經驗、體質 +1 |
| 英文修煉 | 每天學英文後按完成 | +30 經驗、智力 +1 |
| 肉體鍛鍊 | 每次訓練後記錄，一週目標 4 次 | 每次 +50 經驗、力量 +1；達標再 +100 |

- **解禁券**：連續 7 天不吃炸物得一張（另 +50 經驗）。用掉一張可以吃一次炸物而不中斷連續紀錄。
- **補償任務**：昨天破戒或沒學英文，今天會多一個補償任務（+15 經驗）。不做也不會再被追加。
- **忘記回報**：禁炸令可以在隔天補回報昨天的結果；超過一天視同中斷。
- **階級**：見習 → 鐵（5 級）→ 銅（10）→ 銀（20）→ 金（35）→ 傳說（50）。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 頁面骨架 |
| `app.js` | 遊戲邏輯。經驗值、任務目標等數值在最上方，可直接修改 |
| `style.css` | 外觀與配色 |
| `sw.js`、`manifest.webmanifest` | 讓它能安裝到手機主畫面、離線使用 |
| `icons/` | App 圖示 |

紀錄存在手機的瀏覽器裡，不會上傳。換手機前用 App 底部的「備份 / 還原」。

## 版本管理

這個資料夾是一個 Git 版本庫。每次修改後存一個版本：

```bash
git add -A
git commit -m "這次改了什麼"
```

查看歷史版本：

```bash
git log --oneline
```

推送到 GitHub（設定好遠端之後）：

```bash
git push
```
